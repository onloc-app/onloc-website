title: Updates
description: Learn how to update your self-hosted Onloc server and containers using Docker or Podman.
---

In order to update Onloc, you need to pull the latest images from Docker Hub and recreate the containers.

## Docker

```
docker compose pull && docker compose up -d
```

## Podman

```
podman compose pull && podman compose up -d
```
